
# Dataset

## Source

The dataset used for this Loan Default Analysis project was obtained from **Kaggle**.

The original dataset is not included in this repository because the file size exceeds GitHub's standard browser upload limit.

## Dataset Name

**Loan Default Dataset**

## Purpose

The dataset contains customer and loan-related information used to analyze factors associated with loan defaults.

The analysis focuses on variables such as:

* Region
* Gender
* Credit Score
* Loan Purpose
* Business/Commercial Status
* Approval Status
* Loan Default Status

## Data Usage

The dataset was used for:

* SQL-based data analysis
* Default rate analysis
* Credit score segmentation
* Regional analysis
* Customer segmentation
* Power BI dashboard development

## Important Note

The dataset is used for educational and portfolio purposes. The original dataset remains available through its respective Kaggle source.

For reproducing the analysis, download the original dataset from Kaggle and place the CSV file in this folder with the following filename:

```text
Loan_Default.csv
```
