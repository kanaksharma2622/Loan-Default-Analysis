# Loan Default Analysis

## Project Overview
This project analyzes loan customer data to identify patterns and factors associated with loan defaults.

The analysis was performed using SQL for data exploration and analysis, with Power BI used to create an interactive dashboard for visualization and reporting.

## Tools & Technologies
- SQL
- MySQL
- Power BI
- DAX
- Microsoft Excel

## Key Analysis
- Analyzed loan default patterns across different regions
- Calculated overall and region-wise default rates
- Analyzed default behavior based on credit score
- Segmented customers using credit score categories
- Used SQL aggregation, GROUP BY, HAVING, CASE WHEN, and subqueries
- Created an interactive Power BI dashboard to visualize key findings
